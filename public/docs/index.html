Visualização:

API REST de gestão hoteleira do desafio Foco Multimídia: importação de hotéis, quartos e reservas a partir de XML (via cron), CRUD de quartos e motor de reservas com disponibilidade, promoções, cupons, taxas e pagamentos. Todas as respostas são em JSON.

1Selecione um perfil de teste

Clique em Entrar ao lado de um perfil abaixo. O token é aplicado automaticamente em todas as rotas.

2Escolha uma rota

Use o roteiro sugerido ou a busca. O modo Try it out já vem ligado e os exemplos já vêm preenchidos.

3Execute a requisição

A resposta real aparece logo abaixo. Rotas com 🔒 exigem login; as demais são públicas (motor de reservas).

Roteiro sugerido

5 rotas principais, prontas para executar.
  1. GET/availabilityQuartos livres no período, com preço final calculado
  2. POST/reservesCriar uma reserva (retorna o localizador)
  3. POST/reserves/lookup"Minha reserva": localizador + sobrenome
  4. POST/rooms 🔒Cadastrar um quarto (admin ou gerente)
  5. GET/hotels/{hotel}/report 🔒Ocupação, ADR e RevPAR do hotel
